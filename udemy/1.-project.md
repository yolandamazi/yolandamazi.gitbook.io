# #1. Project

## Project Overview

**Step 1: Data Extraction**

* Getting the data we going to use through a Youtube API
* Use a python as main language through a script to extract the data

**Step 2: Data Loading & Transformation**

* Loading implies saving the data to a storage system, usually called a data warehouse, data lake or data lake house. In this project, a data warehouse, that is Postgres
* Transformation meaning we will apply changes to the data to make it more readable or extract the portion of information needed. We will use python again to apply the transformations

> ETL, was traditionally this process, the data would be tranformed and then loaded to the warehouse, but in the pas years there's been a change to ELT, driven by advances in tech since modern data storage solutions can handle large volumes of raw data efficiently

**Step 3: Data Quality Testing**

* The data quality tests are essential to ensure that the data given to the users, f.e. data analysts and scientists, is accurate and reliable, f. e. duplicates or incorrect formats
* We will use a tool called SODA

**Step 4: Functional & End-to-end Testing**

* Testing is a best practice from software development and will set you apart from other data engineers.
* We will do unit test, integration test and end-to-end tests
* We will use two frameworks, Pytest an Unit for unit and integration test, and Airflow's testing features for the end-to-end test

**Step 5: CI/CD Continuous Integration and Continuous Deployment**

* We will use Docker and automated testing
* It helps keep the data pipelines running smoothly when you apply changes to the code
* For this we will use, GitHub actions

### Data extraction using an API

An **API (Application Programming Interface)** is a set of code, rules and protocols that allow different software applications to communicate with each other. To explain it in a easier way it works as an intermediate between a client requesting information needed to a database or server to later on send it to the client, answering to the request made by the client

#### **How to create a Google API:**&#x20;

1. Open <a href="https://console.cloud.google.com" target="_blank">console.cloud.google.com</a>&#x20;
2. Create a new project and name it, in this case, YoutubeAPICourse, and select no organization
3. After creating the API, display de left menu, access to API and services > Library
4. Then scroll down and choose the "Youtube Data API v3"
5. Click on enable and then the Create credentials button
6. Choose the public data option, click the next button and then the API key will display on the screen
7. Press the restrict the key to limit which website IP addresses or apps can call the API with the key, in our case we just wanna acces to the Youtube API v3
8. A new window will pop out, if it's displayed, make sure it says restrict key, and the on the toggle to choose the API restrictions, select the one you are using, Youtube in this case
9. Then, press save
10. You will go back to the previous window, the press public key again and this time press save
11. On the left menu, go to the credentials section under API and services, the API key should be there
12. Make sure you do NOT share this key with anyone, and in this case, once the project is done, you should delete it

#### **Get familiar with the Youtube API**

**—  Basic structure of a resource**

We will use this docs to help us build the URL needed to interact with the API in our Python scripts. To access the API documentation we will search this link [developers.google.com/youtube/v3/docs](https://developers.google.com/youtube/v3/docs). We can access to different types of resources, in our case, we will always use the list method for all the resources. There we will find the JSON structure for the resource.

In terms of important variables, we should find the statistics, which we will for sure use during this project

```json
"statistics": {
    "viewCount": string,
    "likeCount": string,
    "dislikeCount": string,
    "favoriteCount": string,
    "commentCount": string
}
```

If you press on the key, a new page will pop up, with properties of the object statistics.
